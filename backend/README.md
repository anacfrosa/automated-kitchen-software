# Wish and Cook Backend Microservices

An artificial intelligence based food cooking and ordering platform.

## Getting started

Before cloning the project repository make sure you have git and docker installed on your computer. If there is no git and docker go to the git and docker website and try to install these tools first. To clone the repository from Github, use the Github cloning options.

After cloning the repo, go to the project directory and run the following command to create docker images and run containers for all microservices.

```docker
docker compose up --build
```

To get autosuggestions by the npm packages that we are using in our project, you can install all npm dependencies.

```bash
npm install
```
